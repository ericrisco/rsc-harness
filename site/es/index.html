Cómo configurar Claude Code o Codex para un proyecto con rsc

rsc es un instalador gratuito de línea de comandos para agentes de código con IA. Ejecuta npx @ericrisco/rsc@latest onboard en la raíz de tu proyecto: te pregunta el nivel técnico, el acompañamiento, el tipo de proyecto, el objetivo y los asistentes, y lee solo esa raíz. No escribe nada hasta mostrar el plan exacto de componentes seleccionados y pospuestos y hasta que aceptes su id SHA-256 con --accept-plan. Para agentes que leen esta página

Instrucciones: instala rsc en el proyecto del usuario

Si eres un agente de código y tu usuario te pidió instalar rsc / este harness / estas skills, haz lo siguiente, en orden:

agent-instructions
1. Ejecuta onboarding y transmite cada pregunta al usuario. Nunca inventes sus respuestas.
2. Asegúrate de estar en la raíz del proyecto del usuario — no dentro de un clon del repo rsc-harness.
$ npx @ericrisco/rsc@latest onboard
3. Campos no interactivos: --technical-level mixed --accompaniment L1 --project-kind software --goal "web pequeña" --software-scope small --target codex
4. Muestra el plan. Solo cuando el usuario acepte su id exacto, repite con --accept-plan <id-mostrado>.
5. Solo RSC_ONBOARDING_READY confirma una instalación verificada.
6. Deja al usuario listo para trabajar: tras instalar, las skills + hooks no se activan hasta recargar la sesión. Dile que recargue/reinicie (Claude Code: reiniciar · Codex/AGENTS.md: siguiente turno). Tras el reload quedas equipado — orient + suggest siempre activos y bro lista cuando la pidas. Confirma que rsc está listo y deja que el usuario empiece con sus palabras; no auto-arranques una tarea.
⚠ No ejecutes npx @ericrisco/rsc dentro de un clon de este repo — resuelve al bin local sin linkar y falla con "command not found". Usa @latest o node scripts/rsc.js.

Por qué rsc

Granular, honesto, autónomo

La mayoría de packs de skills vuelcan cientos de archivos en tu contexto. rsc apuesta por lo contrario.

Granular por defecto

La unidad de instalación es una skill. Instala fastapi sin arrastrar go. Nada que no uses ocupa el contexto del modelo.

Se auto-recomienda

Un detector siempre activo observa tu trabajo y nombra la próxima skill en cuanto una tarea la necesita — un "sí" la instala.

Con control de calidad

Cada skill se investigó contra fuentes vivas de 2025–2026 y tuvo que superar una rúbrica de comportamiento adversarial de ≥ 8.5/10 antes de publicarse.

No solo código

Más allá de lenguajes y frameworks, rsc puede llevar toda una operación: contabilidad, facturación, RGPD, pitch decks, SEO y presencia en YouTube / TikTok / LinkedIn — cada una conectada a un bucle de conocimiento que aprende de tus propios resultados.

Una base, cada IDE

Los archivos de skill se escriben una vez en tu proyecto y se enlazan en cada asistente que elijas — sin copias duplicadas entre IDEs.
